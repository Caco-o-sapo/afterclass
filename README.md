# After Class — V0.1

Protótipo React + Vite, sem dados reais. Publicações de teste ficam apenas na memória da página. Não há autenticação, persistência, moderação ou integração Supabase nesta versão.

## Executar

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

Hospedagem: framework Vite, comando npm run build, saída dist. Antes de cadastrar alunos reais, implementar autenticação, aprovação, separação de públicos, RLS, moderação e revisar privacidade com a escola.
